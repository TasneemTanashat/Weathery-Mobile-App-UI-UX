# Weathery – Mobile Weather App UI/UX Design

## Overview
Weathery is a mobile weather application concept designed using Figma. The project includes multiple mobile app screens and an interactive prototype, focusing on a clean and intuitive user experience.

## Features
- Multiple mobile app screens
- Interactive prototype
- Clean and intuitive user interface
- Weather information presentation

## Tools
- Figma

## Project Type
UI/UX Design – Mobile Application
